CKINDAT This header record is designated KINDAT=180X.                 
C
C       These data are derived from the Faraday rotation experiment, one
C       of the primary modes of operation of the Jicamarca Radio Observatory.
C       Jicamarca (11.9 deg S, 76 deg W) is a 50 MHz incoherent scatter
C       radar that has been in continuous operation since the early 1960s.
C       The standard Faraday rotation double-pulse experiment (KINDAT=1800) 
C       remains the most suitable for measuring F region plasma density and 
C       temperatures. During the day, the plasma is assumed to be
C       entirely O+, but Te and Ti are permitted to differ. At night,
C       we assume Te=Ti in the fitting but allow for H+ ions.
C
C       In 2000, the Faraday double-pulse experiment was upgraded
C       with the addition of randomized alternating codes (KINDAT=1801).
C       The alternating coded pulses permit accurate parameter estimation 
C       in the topside. Plasma temperature and composition are estimated from 
C       alternating-code data above 450 km altitude, where we assume Te=Ti
C       in the fitting except during a brief interval around sunrise. 
C       Below 450 km, where clutter from the electrojet is strong and ever
C       present, the autocorrelation functions are still estimated from the 
C       double-pulse data. In fitting these data, the plasma is assumed to be
C       entirely O+, but Te and Ti are permitted to differ during the day.
C
C       In 2007, a long-pulse experiment incorporating a full-profile analysis
C       (KINDAT=1802) was introduced to increase sensitivity further. As 
C       in the alternating code experiment, parameters are estimated on 
C       the basis of double-pulse data below 450 km altitude. Above 450 km, 
C       parameters including Te, Ti, H+ fraction, and He+ fraction are 
C       estimated on the basis of the long-pulse data. 
C
C       Users must be aware that radar data acquired at the magnetic dip
C       equator are prone to contamination from coherent scatter associated
C       with plasma irregularities in the equatorial electrojet, the 150-km
C       region, and with equatorial spread F. Complete removal of the strong
C       coherent scatter is not possible, leading to what might be interpreted
C       as anomalously large plasma densities in contaminated regions. All
C       parameters below 140 km (180 km at midday) should be disregarded,
C       as should parameters measured at night during periods of spread F.
C       In cases of doubt, users should contact the data providers.
